# Official source documents

This folder archives the public documents used to populate OpenVote reference data.

Workflow:

1. Add each source to `manifest.json`, or to a focused manifest such as
   `elecam-election-wave-manifest.json` for a large acquisition batch.
2. Download the official PDF into `pdfs/`.
3. Run `scripts/verify-source-documents.py --manifest <manifest>` to compute or verify SHA-256 checksums.
4. Run `scripts/extract-source-pdfs.py --manifest <manifest>` to create text files in `extracted/`.
5. Import structured CSV/JSON only after the PDF and extracted text are reproducible.

The manifest is the human-readable registry. The database table `source_documents`
is the application registry.

## ELECAM 2025 polling-station CSVs

Generate reproducible CSV extracts from the verified ELECAM polling-station PDFs:

```bash
python3 scripts/parse-elecam-2025-polling-stations.py
```

This writes:

- `structured/elecam-2025-polling-stations.csv`: canonical extract with source metadata and per-row confidence.
- `structured/elecam-2025-polling-stations-upload.csv`: upload shape accepted by `/admin/polling-stations/import-csv`, with geographic UUIDs blank.
- `structured/elecam-2025-polling-stations-review.csv`: rows from communes whose parsed totals need review.

To produce an upload CSV with the actual UUIDs from a target database, run:

```bash
DATABASE_URL='postgres://user:password@host:5432/openvote?sslmode=disable' \
  python3 scripts/enrich-elecam-2025-polling-stations-geo.py
```

This writes `structured/elecam-2025-polling-stations-upload-with-geo.csv`
and `structured/elecam-2025-polling-stations-geo-match-report.md`. The
script resolves UUIDs from `regions`, `departments`, and `arrondissements`
by normalized administrative names, because department and arrondissement
UUIDs are generated by the database migrations and must not be guessed.

Import the enriched CSV into `polling_stations` with a transaction guard:

```bash
DATABASE_URL='postgres://user:password@host:5432/openvote?sslmode=disable' \
  python3 scripts/import-elecam-2025-polling-stations.py
```

The import script creates or updates the target 2025 presidential election
record, loads the CSV into a temporary staging table, verifies required
fields, UUID foreign keys, duplicate station codes, and the exact row count,
then upserts into `polling_stations`. The transaction aborts unless the final
imported count is exactly `28 170`.

For a non-default file or election UUID:

```bash
python3 scripts/import-elecam-2025-polling-stations.py \
  --database-url "$DATABASE_URL" \
  --csv-path '/absolute/path/to/elecam-2025-polling-stations-upload-with-geo.csv' \
  --election-id '00002025-0000-4000-8000-000000000001'
```
