# LAM 2025 presidential election maps

This folder archives analytical maps for the 12 October 2025 Cameroon
presidential election.

Source: Les Afriques dans le Monde (LAM), LAMencartes,
`https://www.lesafriquesdanslemonde.fr/cameroun-presidentielle-2025/`.

These files are analytical/cartographic sources, not official result
proclamation documents. Openvote treats them as `secondary_check` evidence for
territorial interpretation:

- participation by department;
- leading candidate by department and vote shares against registered voters;
- Biya vote distribution by department;
- Tchiroma vote distribution by department.

The official numerical baseline for 2025 remains the Conseil constitutionnel
proclamation archived under `data/sources/official`.
